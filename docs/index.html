SMSPit

Mock Twilio SMS & Voice server for developers

Drop-in replacement for Twilio. Real-time web UI (WebSocket), SQLite, compact dark UI with sharp corners. Ideal for local SMS/voice testing.

Fastify + SQLite WebSocket live Twilio SDK compatible ~87% coverage

Usage examples

import twilio from 'twilio';

const client = twilio(
  'ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx',
  'your_auth_token',
  {
    host: 'localhost',
    port: 4010,
    timeout: 30000,
  }
);

await client.messages.create({
  body: 'Hello from SMSPit!',
  from: '+1234567890',
  to: '+0987654321',
});
<?php
$client = new Twilio\Rest\Client('ACxxx', 'token', [
    'host' => 'localhost', 'port' => 4010,
]);
$client->messages->create('+0987654321', [
    'from' => '+1234567890', 'body' => 'Hello from SMSPit!',
]);
